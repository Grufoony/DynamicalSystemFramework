Detailed Description

template<typename T>
class dsf::PtrMapView< T >

Non-owning view over a map of owning pointers, exposing (id, raw pointer) pairs.

The view does not expose the std::unique_ptr, so callers cannot reset or release the owned objects. If T is const, the objects are only accessible as const. The iterators only wrap the map's iterators, so they stay valid after the view itself is destroyed.
