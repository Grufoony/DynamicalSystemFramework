◆ evolve()

StepDataResult dsf::mobility::FirstOrderDynamics::evolve ( StepDataRequest const & dataRequest = {})

Evolve the simulation.

Evolve the simulation by moving the agents and updating the travel times. In particular:

  • Move the first agent of each street queue, if possible, putting it in the next node
  • Move the agents from each node, if possible, putting them in the next street and giving them a speed. If the agent is in the destination node, it is removed from the simulation (and then reinserted if reinsert_agents is true)
  • Cycle over agents and update their times
    Parameters
    dataRequestThe save/collection request for the current step
    Returns
    StepDataResult The collected data for the current step

◆ importTransitionMatrixFromJSON()

void dsf::mobility::FirstOrderDynamics::importTransitionMatrixFromJSON ( std::string_view const fileName)

Import the transition matrix used to route random agents from a JSON file.

Parameters
fileNameThe path of the JSON file

The file must contain an object whose keys are the current street ids and whose values are objects mapping the candidate next street ids to their probabilities, e.g.:

{
"1042": { "1043": 0.6, "1055": 0.2 },
"1043": { "1080": 1.0 }
}

Rows are not required to sum to 1: the probability of ending the trip is always inferred at runtime as one minus the sum of the other probabilities. The imported matrix is then passed to setTransitionMatrix, which validates it.

Exceptions
std::runtime_errorIf the file cannot be parsed or has an invalid structure
std::invalid_argumentIf a key is not a valid street id, if a probability is negative or if a row sums up to more than 1

◆ setAllowRandomUTurns()

void dsf::mobility::FirstOrderDynamics::setAllowRandomUTurns ( bool const allow)
inlinenoexcept

Let random agents take the U-turns of their transition-matrix row.

Parameters
allowThe flag (default true: a U-turn entry of the transition matrix is kept as a normal entry and a random agent takes the U-turn with its probability)

With the flag unset, random agents never take a U-turn outside a roundabout: the U-turn entries of the transition matrix are redistributed over the row, like forbidden turns. It must be set before the transition matrix (setTransitionMatrix, importTransitionMatrixFromJSON), which validates the rows. Streets without a matrix row keep the uniform behaviour, which never takes a U-turn.

◆ setMode()

void dsf::mobility::FirstOrderDynamics::setMode ( DynamicsMode const mode)

Set how origin, destination and OD ids are interpreted.

Parameters
modeDynamicsMode::EDGES for street ids, DynamicsMode::NODES for node ids

In EDGES mode an agent starts from the source node of its origin street and travels it; it also travels its destination street, and arrives, and is removed, at its end. In NODES mode each node id is spread over the node's outgoing streets for an origin, and over its ingoing streets for a destination, with its weight split evenly among them: agents start from the node and arrive when they reach it. Nodes without such streets are skipped. The dynamics itself always works on streets, so origins(), destinations() and destinationStreets() hold street ids in both modes.

Exceptions
std::runtime_errorIf origins, destinations or OD pairs are already set

Set the path randomness.

Parameters

Each agent perceives each street cost multiplied by its own log-normal noise of mean 1, exp(sigma · Z - sigma² / 2) (see Router::noise), the same at every re-plan: agents with the same trip spread over more routes, whatever the weight. Values between 0.1 and 0.5 are sensible

Set the speed function. Options are:

  • (LINEAR, alpha): speed = max_speed * (1 - alpha * moving_density), where alpha is a parameter in [0, 1) and moving_density = n_moving_agents / capacity (queued agents cost queue time instead, see setEdgeWeight)

◆ setTransitionMatrix()

void dsf::mobility::FirstOrderDynamics::setTransitionMatrix ( std::unordered_map< Id, std::unordered_map< Id, double > > const & transitionMatrix)

Set the transition matrix used to route random agents.

Parameters
transitionMatrixThe transition matrix, i.e. a map whose outer key is the current street id, whose inner keys are the candidate next street ids and whose values are the corresponding probabilities

The probabilities of each row must sum up to at most 1: the missing mass is the probability that the agent ends its trip at that junction, which is inferred at runtime and must not be part of the given matrix. Streets which are not a key of the matrix keep the default uniform behaviour. Entries which cannot be used because the destination street is unknown or is not an outgoing edge of the source street's target node are dropped and reported as warnings, which reduces the row's total probability and thus increases the end probability accordingly. Forbidden turns are handled differently: since random agents can never take them, their probability is instead redistributed proportionally among the other entries of the same row, so that the end probability is unaffected by their weights. U-turn entries are kept as normal entries by default; with setAllowRandomUTurns(false), set before the matrix, they are redistributed like forbidden turns. If a row only contains forbidden-turn and/or U-turn entries, there is nothing to redistribute onto and the probability is dropped (reported as a warning) like any other unusable entry.

Exceptions
std::invalid_argumentIf a probability is negative or if a row sums up to more than 1
