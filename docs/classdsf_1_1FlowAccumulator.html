Detailed Description

A deterministic flow gate.

Each time step adds the capacity (agents per time step) without exceeding it, and each agent passing through consume()s one unit, so that the value can become negative. Agents may pass while canPass(). Hence an idle gate lets a lone agent pass at once, while a platoon is released at exactly capacity agents per time step, at most ceil(capacity) in a single step. The gate is refilled lazily: refill() catches up on all the time steps since the previous call, so it only needs calling when an agent tries to pass.

Bring the accumulator up to date with a time step.

Adds the capacity once per time step since the previous refill, without exceeding it: refilling once after k idle time steps is the same as refilling at each of them. The first refill fills the gate, a second one in the same time step has no effect.

Parameters

timeStepThe current time step
